# ENKI ERP — نموذج إدارة العقود (Clickable Mock)

نموذج تفاعلي لوحدة **إدارة العقود** بواجهة ENKI ERP (عربي، من اليمين لليسار). جميع البيانات تجريبية وتُحفظ في متصفحك (localStorage) ويمكن إعادة تعيينها من قائمة المستخدم.

## التشغيل

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # المخرجات في dist/ وتعمل من أي استضافة ثابتة
npm run check    # فحص سلامة البيانات التجريبية
```

## حالة التنفيذ
الوحدات التسع مكتملة: العقود، الاعتماد والتوقيع، الاتفاقيات والتنفيذ، الملاحق والنسخ والتجديد، الالتزامات والمالية، القوالب والطباعة، الخدمة، الإعدادات والصلاحيات، لوحة المؤشرات والتقارير. سجل التنفيذ والتحقق في `WORKLOG.md`.

## جولة سريعة
1. **لوحة المؤشرات** `/` ثم **العقود** `/contracts` وافتح عقداً (بطاقة بـ 15 تبويباً حسب النوع).
2. بدّل **الدور** (مدير عقود، مبيعات، مالية...) لترى اختلاف القوائم والأزرار؛ بدّل **المستخدم المعتمد** لاعتماد المراحل من «مهامي».
3. **الاتفاقيات ← محاكي المستندات**: أنشئ أمراً/تسليماً/فاتورة/مرتجعاً وغيّر إعدادات الإنفاذ ومشاهدة أثرها.
4. قدّم **اليوم التجريبي** (أسبوع/شهر) لترى الانتهاء والتجديد التلقائي وتطبيق الملاحق والتنبيهات وخروقات SLA.
5. **التقارير** `/reports` (17 تقريراً) والبحث الشامل من الشريط العلوي.
6. **الإعدادات** (دور مسؤول النظام): الإعدادات والمصفوفة والترقيم ومراحل الاعتماد وصلاحية البيانات.

## أدوات العرض
- **الدور:** من قائمة المستخدم أعلى اليسار؛ يغيّر الأزرار والقوائم.
- **اليوم التجريبي:** من الشريط العلوي لتجربة الانتهاء والتنبيهات والتأخر والتجديد.
- **محاكاة خطأ الخادم / إعادة التعيين:** من قائمة المستخدم.
