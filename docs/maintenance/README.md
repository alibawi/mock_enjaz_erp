# ENKI ERP — نموذج إدارة الصيانة (Clickable Mock)

نموذج تفاعلي لوحدة **إدارة الصيانة** داخل `mock_enjaz_erp` بجوار الموجودات الثابتة والعقود (عربي، من اليمين لليسار). مبني على خطة الصيانة المعتمدة (`source/maintenance-management-implementation-plan.md`) ومنهج `source/mock-playbook-en.md`. البيانات تجريبية في المتصفح (localStorage، المفتاح `enki-maintenance-mock`)، ويمكن إعادتها من قائمة المستخدم ← «إعادة البيانات».

التكاملات مُحاكاة داخل الوحدة وتحمل وسم «مُحاكى — في النظام الحقيقي: …»: المخزون (حجز وسند صرف `GI-`)، المبيعات (فاتورة خدمة `INV-`)، المالية (سند قبض/عربون `RC-` والقيود)، الموارد البشرية (الحضور والإجازات). صفحة «الصيانة» في الموجودات الثابتة لم تُمَس.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح `#/maintenance`. التحقق: `npm run check` (يشمل `check:maintenance` — 64 فحصًا للمسار الكامل) و`npm run build`.

**تاريخ العرض:** السبت 7 تشرين الثاني 2026، ويُغيَّر من شريط الأعلى (±1/7/15/30 يومًا) لعرض انتهاء التقديرات وبدء الحجوزات المستقبلية. **الدور:** من قائمة المستخدم أعلى الشاشة؛ الأزرار والقائمة والصفحات تتبع مصفوفة الصلاحيات.

## سيناريو عرض (15 دقيقة)

1. **الاستقبال (سارة — موظفة استقبال):** طلب جديد لكامري أحمد ← لاحظ تنبيه إعادة العمل ← سجّله عاديًا ← إيصال الاستلام.
2. **التقدير:** «تحضير تقدير» ← قطعتان + عمالة بخصم 20% ← المعاينة تقول «يحتاج مدير الورشة» ← إرسال.
3. **الاعتماد (حيدر — مدير الورشة):** «مهامي» ← اعتماد. جرّب اعتماد MES-…048 الذي قدّمه حيدر بنفسه ← مرفوض (فصل المهام).
4. **موافقة العميل (سارة):** رد العميل ← وافق هاتفيًا ← «إنشاء أمر عمل» مع عربون.
5. **الجدولة (زينب — المنسقة):** لوحة الجدولة ← «حجز» من قائمة «بانتظار الجدولة» ← جرّب فنيًا محجوزًا أو في إجازة.
6. **التنفيذ (حيدر):** بطاقة أمر العمل ← بدء (تُحجز القطع) ← الكميات المستهلكة ← فحص الجودة ← إكمال بكود العطل ← سند الصرف وقيده.
7. **الفوترة (نور الهدى — المحاسبة):** إصدار الفاتورة (يُسوّى العربون) ← محاولة الإلغاء مرفوضة ← قبض الباقي ← إغلاق الأمر (حيدر).
8. **استثناءات جاهزة:** رافعة المخزن (فشل الصرف ← إعادة المحاولة)، أمر حساس الأوكسجين (رفض البدء)، مسار ميداني بزيارتين يوم الاثنين 9/11 (غيّر تاريخ العرض +2 ثم ابدأه).
9. **الإدارة:** التقارير ← ربحية أوامر العمل، الإصلاح من المرة الأولى، الذمم ← سجل التدقيق.
